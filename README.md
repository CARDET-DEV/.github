# .github

Organization-wide defaults for CARDET.

Files here are inherited by every repository in the org that doesn't
define its own.

| File | Applies to |
|---|---|
| `PULL_REQUEST_TEMPLATE.md` | PR description prefill |
| `CONTRIBUTING.md` | Branching and review conventions |
| `ISSUE_TEMPLATE/` | New issue forms |
| `SECURITY.md` | Vulnerability reporting |
| `profile/README.md` | Public org profile page |

Editing any of these changes behaviour across all repositories.
Open a PR rather than committing directly.
